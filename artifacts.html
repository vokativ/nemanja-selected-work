Korak do glasa

Civic-tech diaspora voter-registration platform for Serbia's 2026 election cycle — combining client-side zero-PII registration PDF generation with a public follow-up procedure and machine-readable instructions for external AI agents.

Live Civic Tech Copy link
2026 election refresh 16 canonical templates Zero server-side PII
Trust boundary: Zero server-side case data. Opening agent.md provides no email access; no drafting or sending without explicit human sign-off.
Challenge

Serbian citizens abroad face a clumsy, high-friction registration process across dozens of diplomatic missions with strict deadlines. After submitting, applicants frequently face weeks of administrative silence or ambiguous acknowledgements with no tracking mechanism or guidance on strict legal appeal windows (often 24–48 hours).

What I built

Originally created hocudaglasam.com in 2020 and refreshed the platform for Serbia's 2026 parliamentary election cycle as Korak do glasa (korakdoglasa.org). Rebuilt the frontend as a React 19 / TypeScript application using Vite and Bun, hosted on Firebase. Built an automated Python ingestion and verification pipeline that audits Ministry of Foreign Affairs directories and mission portals, enforces evidence citations before promoting newly published election mailboxes, and exposes a strict four-state coverage contract (confirmed, partial, notice-published, unconfirmed).

The browser generates official voter registration PDFs locally with an embedded Cyrillic font and optional client-side ID document attachment. Zero applicant personal data or documents ever reach project servers; the completed PDF is handed off directly to the user's system mail client.

Post-submission follow-up & AI agent instructions: Expanded the platform with a complete post-deadline follow-up system (/pracenje/ in Cyrillic and Latin). Rather than hosting an AI service that inspects personal inboxes, the site publishes an open operating procedure: 16 canonical correspondence templates (T01–T16) in templates.json, a machine-readable decision tree in workflow.json, an official legal source catalog in sources.json, and a dedicated AI agent playbook (/pracenje/agent.md) with one-click handoff to ChatGPT, Claude, and Gemini.

The agent playbook enforces strict permission and agency boundaries: visiting a URL is not permission to read private email; reading email does not permit saving drafts; saving drafts does not permit sending; and legal appeals require separate explicit authorization. The model must report along an explicit 5-step status ladder (text prepared → draft saved → message sent → receipt confirmed → filing proven) and distinguish preliminary acknowledgements from final polling place decisions.

Status & Delivery

Live at korakdoglasa.org for the 2026 election cycle. Open source on GitHub with automated recipient verification and station coverage tests. (The historical 2020 domain hocudaglasam.com lapsed after prior cycles and now hosts unrelated third-party content; all current operations are maintained under korakdoglasa.org).

Adiufant

Production AI calendar assistant & task manager for busy parents — turning family-related images, PDFs, voice notes, shared files, and calendar screenshots into structured calendar events and preparation checklists with scheduling safeguards.

Live Product Copy link
Two app stores → Android + iPhone Review before action → local-first Auto-reschedule & undo → safeguards
Trust boundary: Save-first review; temporal grounding guardrails detect prior-year hallucinations; nothing reaches device calendar without explicit user confirmation.
Challenge

While coordinating two children's lives, my wife and I found that even a shared calendar solved only part of the problem. Information arrived through school apps, chats, flyers, PDFs, screenshots, voice notes, and work calendars; entering it was a constant time tax, and a date alone did not capture what had to be brought, signed, paid, or prepared beforehand.

What I did

I tested model feasibility in early 2025, built a web demo over the summer, and learned that a browser upload flow was too clunky because parents' source information lives on their phones. I then owned the mobile product, architecture, implementation, testing, customer discovery, and store releases end to end, using AI development tools throughout.

Underneath, Drift remains the device source of truth; authenticated users can sync through Firestore; and media flows through authenticated Firebase callable functions to Gemini with App Check protection before normalized suggestions are saved for an explicit accept-or-skip review. To make AI dependable in daily use, built temporal grounding guardrails to detect and fall back from prior-year resolution hallucinations on undated notices. When an event date is adjusted, a dedicated reschedule engine dynamically updates derived preparation task deadlines, pairing instant slide-fade feedback with an inline undo action. System share targets are isolated from capture flows to preserve original event start dates.

Status & Delivery

Built and published through Vulcanus Holdings, Inc. and live at adiufant.com, on the Apple App Store (v1.3.1, build 25), and on Google Play (v1.3.0, build 25). Iterative releases added dynamic prep-task auto-rescheduling with inline undo, temporal hallucination guards, and crash hardening. Early feedback is positive, but it is too soon to claim retention or scaled adoption.

RedMart Grocery Cart Helper

Open-source AI agent workflow that turns messy family whiteboard photos, voice notes, or shorthand lists into prepared grocery carts on RedMart / Lazada Singapore — using constrained AI, canonical SKU matching, and human-in-the-loop review.

Open-Source AI Agent Copy link
Whiteboard → verified cart Canonical SKU & alias matching Stops before checkout
Trust boundary: Proposed cart previewed before any browser mutation. Stops at CAPTCHAs and never bypasses; zero automated checkout or payment.
Challenge

When Amazon Fresh discontinued service in Singapore, our family moved to RedMart. Finding 20–30 known products, fixing quantities, and securing delivery slots became a recurring weekly chore competing with jobs and family time. Yet after a couple of months, household choices were already solved: we already knew which eggs, detergent, fruit, and bread we buy. We didn't need AI to invent new shopping trips; we needed help completing a familiar repetitive task consistently.

What I built

Built an open-source agent workflow around a core engineering principle: The family makes decisions once; the agent handles the repetition. Rather than letting an LLM guess arbitrary products on a retailer website, the architecture constrains the agent's action space through a structured household YAML catalog.

Family shorthand maps to catalog aliases, default quantities, and family mixes (e.g. “fruit mix” expanding into member items). Products are grounded by canonical retailer item_id and sku_id identifiers, with ranked backup products when first choices are unavailable within delivery windows.

Operational discipline & verification: Enforces the principle that an action is not an outcome. Clicking “Add to cart” does not prove success: buttons may fail, items may be out of stock, or items may collapse into promotion bundles. The agent verifies actual cart table rows, canonical identifiers, pack sizes, and quantities. If state cannot be verified, it reports uncertainty rather than hallucinating success.

Ergonomic multi-device workflow: The list starts wherever life happens—snap a whiteboard photo, dictate a voice note, or type shorthand on a phone via ChatGPT Remote. The repetitive browser automation runs on a paired desktop host (Mac or Windows in Codex mode) where the logged-in RedMart session resides. Also supports OMP browser alternative and OS-level accessibility fallbacks.

Status & Delivery

Open source on GitHub at vokativ/grocery-shopping-redmart. Features synthetic catalog validators, unit test suites for alias resolution and review rendering, and documented browser connection hierarchies. Supervised runs with 5.6 Terra / Medium produced verified carts; stops before checkout so delivery slot selection and payment always stay with the human.

GitHub repo Architecture Case Study Developer Guide Open-source AI agent, ChatGPT Desktop / Codex, OMP browser, YAML catalog, SKU resolution, Bounded fallbacks, Multi-device pairing, Node.js

Constrained agent pipeline: list to verified cart

1. Multimodal input: Photo of kitchen whiteboard, voice note, or casual shorthand (“persil powder”, “eggs”).
2. Canonical catalog matching: Resolves family aliases against YAML catalog with explicit item_id, sku_id, and default quantities.
3. Human review boundary: Proposed cart previewed in chat; human confirms or edits (“skip ham this time”) before browser touches RedMart.
4. Browser cart mutation: Desktop browser operates logged-in session, verifies stock, and applies ranked backups if unavailable within 2 days.
5. Outcome verification: Reads actual cart table rows, canonical identifiers, pack sizes, and promo bundles (“action ≠ outcome”).
6. Human checkout: Agent halts with cart ready; user chooses delivery slot, reviews total, and pays. Zero automated checkout.

Prepiši

Privacy-first offline browser extension for reading Serbian, Croatian, Bosnian, and Montenegrin web text in a preferred script and pronunciation — with 100% client-side conversion and zero page-text upload.

Published Extension Copy link
Three stores → Chrome, Firefox & Edge 137 curated media families Zero network requests
Trust boundary: 100% client-side conversion; 4,102 verified linguistic rules; zero LLMs, zero network requests, zero page-text upload.
Challenge

I grew up reading both Latin and Cyrillic and encountering Serbian, Croatian, Bosnian, and Montenegrin variants. It was frustrating that modern regional websites usually offered only the script easiest for them to publish and one institutionally favored dialect. I wanted one-click control over how everyday news and other web content looked to me, while preserving rather than flattening that diversity.

What I built

Built a shared local conversion engine in TypeScript/JavaScript with strict boundary protection. Rather than relying on non-deterministic LLMs at browsing time, the extension uses 4,102 verified linguistic transformation rows, bidirectional Latin-Cyrillic mapping, and curated phonetic rules for Ekavian, Ijekavian, and Ikavian variants. The content engine safely protects code, forms, URLs, emails, brands, handles, and foreign-language spans while observing dynamic DOM mutations.

Authored a dependency-free Node packaging pipeline with byte-level archive validation and cross-browser manifest handling (Manifest V3). Managed browser-specific permission and lifecycle differences across Chrome, Firefox (desktop + Android), and Microsoft Edge.

Status & Delivery

Version 0.9.3 is published and live on Mozilla Firefox Add-ons (desktop + Android), the Chrome Web Store, and Microsoft Edge Add-ons. The engine is backed by 92 offline unit/integration tests and 12 headless-Chrome DOM checks, with a curated catalog of 137 regional media families (generating 600 explicit Firefox host permission patterns). Operates entirely offline with no analytics, telemetry, or remote text processing.

The Premise Lab

A public, open-source example of using AI to think before building: surfacing hidden premises, testing real-world assumptions, and turning rough ideas into sharper artifacts.

Public open source Copy link
Open source + Gemini + Opal AI for judgment, not just code Philosophy as a build tool
Trust boundary: Explicit falsification criteria; stress-tests assumptions before code is written; requires verifiable counter-evidence.
Challenge

AI is getting good at building — which lets weak ideas harden faster. The expensive failure comes earlier: unclear premises, vague words, and hidden beliefs about how the world works.

What I did

Built a public, open-source thinking partner combining philosophy, behavioral science, and systems thinking, so you can examine an idea before building it. It asks what must be true, what would prove the idea wrong, and which words carry more confusion than meaning — without making you perform intelligence for the machine.

Impact

A rough thought becomes a working hypothesis, a clearer brief, a reality test, and a ledger of assumptions still owed to the world — AI used to improve judgment before action.
